## Stage 3 Code
This folder contains the local code for the different models. 


**MNIST**:
- **Arya**: contains MNIST model code files to be called in the final script (final MNIST CNN model)
- Chenxuan:  contains MNIST model code files to be called in the final script (not the final MNIST CNN model)


**ORL**:
- **Arya**: contains deep ORL CNN model code files to be called in the final script (one of two final ORL CNN models)
- **Jeslyn**: contains ResNet-18 ORL model code files to be called in the final script (second ORL CNN model)


**CIFAR-10**:
- Arya: contains CNN model code files for CIFAR-10 to be called in the final script (not the final CIFAR-10 model)
- **Luna**: contains deep CNN model code files for CIFAR-10 to be called in the final script (final CIFAR-10 model)
- Ryan: contains simple CNN model code files for CIFAR-10 to be called in the final script (not the final CIFAR-10 model)
