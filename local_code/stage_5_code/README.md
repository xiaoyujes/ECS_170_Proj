## Stage 5 Code

This folder contains the local code for the GCN models for the three datasets.

- Arya: contains local code files for the CiteSeer dataset (not final model)
- **Chenxuan**: contains the local code files for CORA, CiteSeer, and PubMed datasets (final models for CiteSeer and PubMed)
- **Jeslyn**: contains the local code files for CORA, CiteSeer, and PubMed datasets (final CORA model)
- cora_gnc_Luna: contains code to run CORA model
