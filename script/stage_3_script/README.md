## Stage 3 Script
This folder contains the final model script files for the ORL, MNIST, and CIFAR-10 datasets.

**MNIST**:
- **Arya**: contains the script file for the MNIST dataset (final MNIST model chosen)

**ORL**:
- **Arya**: contains the script file for the deep CNN ORL model (one of two final ORL models chosen)
- **Jeslyn**: contains the script file for the ResNet-18 CNN ORL model (second ORL model)

**CIFAR-10**:
- Arya: contains the script file for the CNN model on the CIFAR-10 dataset (not the final CIFAR-10 model chosen)
- **Luna**: contains the script file for the deep CNN model on the CIFAR-10 dataset (final CIFAR-10 model chosen)
- Ryan: contains the script file for the simple CNN model on the CIFAR-10 dataset (not the final CIFAR-10 model chosen)
